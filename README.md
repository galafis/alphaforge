### 🚀 Quick Start

#### Prerequisites
- Rust 1.75+ (with cargo)


#### Installation

1. **Clone the repository**
```bash
git clone https://github.com/galafis/alphaforge.git
cd alphaforge
```

2. **Build the project**
```bash
cargo build --release
```

#### Running

```bash
cargo run --release
```
